---

Find yourself stuck using the package? Found a bug? Do you have general questions or suggestions for improving the media library? Feel free to [create an issue on GitHub](https://github.com/jackardios/laravel-medialibrary/issues), we'll try to address it as soon as possible.

If you discover a security issue, please report it [privately on GitHub](https://github.com/jackardios/laravel-medialibrary/security/advisories/new) instead of using the issue tracker.
